## What are Decorators?

Decorators in Python are special functions designed to modify the behavior of other functions or methods without needing to interfere with their source code. They take a function as an argument, add additional logic to it, and return a modified version.

The syntax of a decorator looks as follows:

```python
@decorator
def function(arguments):
    # function body
```

In the Aiogram library, decorators are actively used for handling various events. With their help, it is convenient to register handlers — for example, for receiving a message from a user or pressing a button, which makes the bot's structure more understandable and flexible.

## Using Decorators

*This course was downloaded for free from the site https://ssl.band/ - Join the closed educational platform!*

After creating a bot, a user can begin interacting with it by sending messages. So that the bot can "catch" these messages and reply to them, special decorators are used in Aiogram. One such decorator is `@dp.message()`, which is placed over a handler function. This decorator allows the bot to automatically call an asynchronous function upon receiving a new message. The `message` object, containing all information about the received message, is passed as an argument to the function. When the handler successfully triggers, a corresponding notification will appear in the console.

```python
@dp.message()
async def func(message):
    print("Someone wrote")
```

Besides handling text messages, Aiogram allows you to handle other types of interactions, for example, pressing buttons in the interface. The `@dp.callback_query()` decorator is used for this. In this case, a `call` object, which contains information about the press, is passed to the handler function.

```python
@dp.callback_query()
async def func(call):
    print("Someone pressed")
```

This handler is activated when a user presses a button attached under a message, which allows the bot to react to user actions.
