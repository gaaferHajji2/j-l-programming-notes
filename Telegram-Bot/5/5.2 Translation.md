## Writing a Message Handler

All subsequent training code will be written in the `main.py` file, where the bot instance is created.

Let's write a simple message handler:

```python
# Decorator
@dp.message()
async def start(message):
    print("User wrote to the bot")
```

To make the bot reply to a user, use the `message.answer(text)` method, which takes the text to be sent to the user as an argument.

```python
# Decorator
@dp.message()
async def start(message):
    # Reply to the message
    await message.answer("Hello there!")
```

The **await** keyword indicates that the execution of the next expression may be suspended until it completes, allowing other tasks to run concurrently. This is important for optimizing bot performance so it can handle multiple requests simultaneously without blocking the main execution thread.

**Important:** When calling asynchronous methods in the Aiogram library, you must use `await`, otherwise the code will not work as expected and the bot may freeze or stop responding to messages.

## Organizing Project Texts

Create a file `start.py` in the `texts` directory. In it, create a text variable that will be sent to the user in response to their message.

```python
hello = 'Hello there!'
```

Then import the module containing this text and specify the path to this variable in the corresponding handler.

```python
import texts.start

@dp.message()
async def start(message):
    await message.answer(texts.start.hello)
```

This technique helps structure code by separating the bot's logic from text messages. This is especially useful in large projects with many texts and handlers, as it allows:

- Saving space in handler files, making code more readable and easier to maintain
- More convenient editing and updating of texts without affecting the bot's core logic
- Easy localization of the application by creating separate text files for each language

It's important to note that the message text sent through the `answer` method must be shorter than **1024 characters**. This limitation is related to the Telegram API.

> *In the following course content, moving texts to separate modules will be disregarded for the purpose of improving the clarity of the provided code.*

## Simple Message Filtering

As one of the arguments in the decorator, you can use a filter based on message content so that the function triggers only for specific content.

```python
from aiogram import F

@dp.message(F.text == 'Hello')
async def start(message):
    await message.answer("Hello there!")
```

In this example, `F.text` is a filter that checks the text of the sent message. If the user's message text matches the specified word "Hello", the bot will send the reply message "Hello there!"
