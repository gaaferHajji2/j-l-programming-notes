## English Translation: PostgreSQL Installation

To install PostgreSQL, you need a program that can be downloaded from the company's website. For downloading, it is better to choose the latest version of the installer.

The further process consists of only five steps. Let's consider the example of installing PostgreSQL for Windows.

1. **Launch the installer.** After downloading the installer file, launch it by double-clicking with the mouse.

2. **Select installation folder.** Specify the directory where the program will be installed and click the Next button.

3. **Select installation components.**

4. **Select data storage folder.** Specify the location for storing PostgreSQL data and click Next. At this stage, you may be prompted to enter connection parameters such as host, port, and others. It is recommended to use the following default settings:
   - Host: localhost
   - Port: 5432
   
   If PostgreSQL was previously installed and then removed or updated, the system may offer a different port, for example, 5433. Remember the port number, as it will be needed to connect to the server.

5. **Set password.** During installation, you will be prompted to set a password for the superuser postgres. Be sure to set and remember this password, as it will be required to access the server.

6. **Complete installation.** Before completing the installation, the program will offer to check the settings. Wait for the installation to complete and close the installation process.

### Installation on Other Operating Systems

PostgreSQL installation will be the same for any operating system except Linux. The DBMS developers recommend installing the program on Linux via the command line — repository.
