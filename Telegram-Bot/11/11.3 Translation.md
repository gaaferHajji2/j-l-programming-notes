### Using the INSERT Operator to Add Data

To add data to a table, the **INSERT** operator is used. Let's add a new user to the "Users" table:

```python
cursor.execute('INSERT INTO Users VALUES(%s, %s, %s, %s, %s);', 
               (1765434539, '@jlosos1856', 'Илья', 25, 'jlosos1856@gmail.com'))
```

When creating the query, we specified that we would add records to all existing cells in the table.

### Updating Records Using UPDATE

To update a record in a table, the **UPDATE** operator is used. For example, let's change the age of the user we just added:

```python
cursor.execute('UPDATE Users SET age = %s WHERE user_id = %s;', (29, 1765434539))
```

When creating the query, we specified that we would change the user's age to 29 where user_id = 1765434539.

### Deleting Data Using the DELETE Operator

To delete a record from a table, the **DELETE** operator is used. For example, let's delete the user we created earlier:

```python
cursor.execute('DELETE FROM Users WHERE user_id = %s;', (1765434539,))
```

Thus, we deleted the user with user_id = 1765434539.

### Using SQL Queries to Extract Data from Tables

Let's execute a query to select all users from the "Users" table:

# Select all users
cursor.execute('SELECT * FROM Users')

### Applying SELECT, FROM, WHERE, GROUP BY, HAVING, ORDER BY Operators

One of the powerful tools of SQL is the ability to perform complex queries using **SELECT**, **FROM**, **WHERE**, **GROUP BY**, **HAVING**, and **ORDER BY** operators. These operators allow you to filter, group, and sort data to obtain the desired results.

#### Using SELECT, FROM, WHERE Operators

Let's display the username and age if the age is greater than 25 years:

```python
# Select names and ages of users older than 25 years
cursor.execute('SELECT username, age FROM Users WHERE age > %s', (25,))
results = cursor.fetchall()
for row in results:
    print(row)
```

#### Examples of GROUP BY and HAVING Operators

The **GROUP BY** operator is used to group data by specific columns. The **HAVING** operator is applied to aggregate functions to filter group results.

```python
# Get average age of users for each age
cursor.execute('SELECT age, AVG(age) FROM Users GROUP BY age')
results = cursor.fetchall()
for row in results:
    print(row)

# Filter groups by average age greater than 30
cursor.execute('SELECT age, AVG(age) FROM Users GROUP BY age HAVING AVG(age) > %s', (30,))
filtered_results = cursor.fetchall()
for row in filtered_results:
    print(row)
```

#### Examples of ORDER BY Operator

The **ORDER BY** operator is used to sort results by specified columns. **DESC** means sorting in descending order.

```python
# Select and sort users by age in descending order
cursor.execute('SELECT username, age FROM Users ORDER BY age DESC')
results = cursor.fetchall()
for row in results:
    print(row)
```

#### Combining Operators

You can combine operators to perform more complex queries. For example, let's select users whose average age in the group is greater than 30:

```python
# Select and sort users by age in descending order
cursor.execute('''
SELECT username, age, AVG(age)
FROM Users
GROUP BY age
HAVING AVG(age) > %s
ORDER BY age DESC
''', (30,))
results = cursor.fetchall()
for row in results:
    print(row)
```

### Using Aggregate Functions: COUNT, SUM, AVG, MIN, MAX

Aggregate functions allow you to calculate values across groups of data or over the entire table. Let's look at each aggregate function with examples.

#### COUNT - Counting the Number of Records

The **COUNT** function is used to count the number of records in a column or table. Example of counting all users in the table:

```python
# Count total number of users
cursor.execute('SELECT COUNT(*) FROM Users')
total_users = cursor.fetchone()[0]
```

#### SUM - Summing Numeric Values

The **SUM** function calculates the sum of numeric values in a column.

```python
# Calculate sum of ages of all users
cursor.execute('SELECT SUM(age) FROM Users')
total_age = cursor.fetchone()[0]
```

#### AVG - Calculating Average Value

The **AVG** function calculates the average value of numeric data in a column.

```python
# Calculate average age of users
cursor.execute('SELECT AVG(age) FROM Users')
average_age = cursor.fetchone()[0]
```

#### MIN - Finding Minimum Value

The **MIN** function finds the minimum value in a column.

```python
# Find minimum age
cursor.execute('SELECT MIN(age) FROM Users')
min_age = cursor.fetchone()[0]
```

#### MAX - Finding Maximum Value

The **MAX** function finds the maximum value in a column.

```python
# Find maximum age
cursor.execute('SELECT MAX(age) FROM Users')
max_age = cursor.fetchone()[0]
```

### Example Query with Subquery

To perform complex queries, you can use table joins and subqueries. For example, let's find all users with the highest age in the table:

```python
# Find users with the highest age
cursor.execute('''
SELECT username, age
FROM Users
WHERE age = (SELECT MAX(age) FROM Users)
''')
oldest_users = cursor.fetchall()
# Display results
for user in oldest_users:
    print(user)
```

### Processing Results

#### Getting Query Results as a List of Tuples

Query results are usually returned as a list of tuples. Each tuple represents a row of data. Let's display the results of a query to select all users:

```python
# Select all users
cursor.execute('SELECT * FROM Users')
users = cursor.fetchall()
# Display results
for user in users:
    print(user)
```

#### Using fetchone(), fetchmany(), and fetchall() Methods to Retrieve Data

Additionally, you can use the **fetchone()**, **fetchmany()**, and **fetchall()** methods to retrieve data one row at a time, several rows, or all rows respectively. Let's look at examples:

```python
# Select the first user
cursor.execute('SELECT * FROM Users')
first_user = cursor.fetchone()
print(first_user)

# Select the first 5 users
cursor.execute('SELECT * FROM Users')
first_five_users = cursor.fetchmany(5)
print(first_five_users)

# Select all users
cursor.execute('SELECT * FROM Users')
all_users = cursor.fetchall()
print(all_users)
```

#### Converting Results to More Convenient Data Structures (Lists, Dictionaries)

For convenient data processing, you can convert query results into more convenient data structures such as lists or dictionaries. Let's convert the results of a query to select all users into a list of dictionaries:

```python
# Select all users
cursor.execute('SELECT * FROM Users')
users = cursor.fetchall()
# Convert results to a list of dictionaries
users_list = []
for user in users:
    user_dict = {
        'id': user[0],
        'username': user[1],
        'email': user[2],
        'age': user[3]
    }
    users_list.append(user_dict)
# Display results
for user in users_list:
    print(user)
```

#### Handling NULL Values

**NULL** is a special value indicating the absence of data. When processing NULL values, you can use the **IS NULL** and **IS NOT NULL** operators. For example, let's select users with unknown age:

```python
# Select users with unknown age
cursor.execute('SELECT * FROM Users WHERE age IS NULL')
unknown_age_users = cursor.fetchall()
# Display results
for user in unknown_age_users:
    print(user)
```
