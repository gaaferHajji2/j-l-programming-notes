## Inline Handler

Let’s recall how inline button presses are handled.

Consider a situation where someone clicks an inline button. The corresponding handler is activated.

```python
@router.callback_query()
async def func(call):
    await call.message.answer('Thank you for clicking')
```

Here, `call.message.answer` responds to the user’s action, just like `message.answer` does in message handlers.

## Closing the Callback

After clicking a button, the user will see the button flicker for about 10 seconds. This flickering means the bot is expected to respond and also prevents the user from clicking the button again while it is flickering.

Therefore, at the end of every callback handling handler, a method to remove the flickering (i.e., closing the callback) is typically used. This lets the user know that the bot has fully responded. This is useful when it’s not intuitive how many messages the bot should send in response or how many actions should be performed. The flicker is removed as follows:

```python
@router.callback_query()
async def func(call):
    await call.message.answer('Thank you for clicking')
    await call.answer()
```

Now the user understands that the bot has received the request and is preparing a response. Additionally, the button can be clicked again.

## When Is This Not Needed?

There are cases where a large number of simultaneous tasks can put a load on the server and the bot. This can cause freezes, and our program will respond to user requests with delays. Therefore, when a button triggers a complex subroutine, to prevent freezes, you can prevent users from clicking that button too often. The simplest way is not to reinvent the wheel and use a built-in method: do not close the callback — this will give the bot a “break”.

## Popup Messages

The `call.answer()` method has another useful feature — popup messages. To use such messages, you need to pass the text that will appear on the screen as an argument to this method.

```python
@router.callback_query()
async def func(call):
    await call.message.answer('Thank you for clicking')
    await call.answer("Done")
```
