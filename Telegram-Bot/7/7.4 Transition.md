# Translation: Sending Different Types of Messages

## Sending Images

If you want to send a photo named "example.png" located in your project directory, you first need to load it using the `FSInputFile("example.png")` method, and then send it using the `message.answer_photo(img, caption)` method, where:
- **img** — the loaded image
- **caption** — description/caption for this image

```python
from aiogram.types import FSInputFile

@router.message(F.text == 'image')
async def image(message):
    img = FSInputFile("files/media/STUDY.png")
    await message.answer_photo(img, 'Study with us!')
```

This is how it will look in the bot:
> *[Bot displays the image with the caption "Study with us!"]*

---

If you want to send a photo from the internet using a known URL, use a different method to load it: `URLInputFile(url)`, where **url** is the web address of the image.

```python
from aiogram.types import URLInputFile

@router.message(F.text == 'image')
async def image(message):
    img = URLInputFile("https://zelenyimir.ru/wp-content/uploads/2023/03/moree.jpg")
    await message.answer_photo(img, "Let's go to the sea!")
```

This is what the bot will output:
> *[Bot displays the image with the caption "Let's go to the sea!"]*

## Sending Other Types of Messages

Similarly, you can send other types of data:

### 1. Documents:
```python
@router.message(F.text == 'file')
async def send_file(message):
    file = FSInputFile("1.txt")
    await message.answer_document(file)
```

### 2. Video:
```python
@router.message(F.text == 'video')
async def send_video(message):
    video = FSInputFile("1.mp4")
    await message.answer_video(video)
```

### 3. GIF/Animation:
```python
@router.message(F.text == 'gif')
async def send_gif(message):
    gif = FSInputFile("1.gif")
    await message.answer_animation(gif)
```

### 4. Video Message (Video Note):
```python
@router.message(F.text == 'circle')
async def send_circle(message):
    video_message = FSInputFile("1.mp4")
    await message.answer_video_note(video_message)
```

> In the same way, you can send other, less frequently used data types such as: **audio**, **stickers**, **polls**, and more. To learn about them in detail, we recommend referring to the [official documentation](https://docs.aiogram.dev/).
