# Translation: Message Filtering by Type. Broadcasting

## Filtering Messages Using Images as an Example

Let's create a handler. As an argument to the decorator, we specify `F.photo`, which will return an object containing information about the sent photo if it exists, otherwise it will return `None` and the filter will skip this handler.

```python
@router.message(F.photo)
async def photo(message):
    await message.answer("You sent a photo")
```

If the sent message is a photo, the bot will respond to the user accordingly.

The method `message.photo[-1].file_id` allows you to get the ID of the sent photo in the highest quality. If you specify `0` instead of `-1`, the quality will be the lowest available for download. The `file_id` can be used to resend the image.

```python
@router.message(F.photo)
async def photo(message):
    file_id = message.photo[-1].file_id
    await message.answer_photo(file_id, "Your photo!")
```

## Broadcasting

The technique from the previous section can be used, for example, to create a broadcast feature. Using the `bot.send_photo()` method, you can send a photo to a user by specifying their `user_id`, `file_id`, and the text to send. To use this, we import the `bot` object from the `main.py` file.

In the handler, we add a filter for messages containing images. We create a loop that iterates through a list of user IDs and sends a photo to each user using the method mentioned above.

```python
users = [1046276866, 1234567890, 290290099]

@router.message(F.photo)
async def photo(message):
    from main import bot
    file_id = message.photo[-1].file_id
    for user_id in users:
        await bot.send_photo(chat_id=user_id, photo=file_id, caption="Advertisement!")
```

Thus, each user from the list will receive a broadcast consisting of a photo and the text "Advertisement!".

Let's improve this code: instead of using predefined text, we'll use the text sent along with the image by using `message.caption`.

```python
users = [1046276866, 1234567890, 290290099]

@router.message(F.photo)
async def photo(message):
    from main import bot
    file_id = message.photo[-1].file_id
    for user_id in users:
        await bot.send_photo(chat_id=user_id, photo=file_id, caption=message.caption)
```

Ultimately, we obtained a broadcast that is sent to each user in the list. In the future, we could add functionality to retrieve user IDs from a database instead of a hardcoded list.

> **Note:** You cannot write random IDs in the `users` list. If you attempt to send a message to an ID belonging to a person who does not use this bot (i.e., the chat does not exist), **aiogram** will raise a corresponding exception.

## Other Message Filters

Besides `F.photo`, there are other filters:

| Filter | Description |
|--------|-------------|
| `F.video` | Filters video messages |
| `F.document` | Filters file attachments |
| `F.sticker` | Filters stickers |
| `F.animation` | Filters GIFs/animated files |
| `F.voice` | Filters voice messages |

These are specified in the same way as the previous ones: as arguments in the message handling decorator.

Such filters are used less frequently than `F.text` or `F.photo`, but depending on your bot's requirements, you can find applications for them.
