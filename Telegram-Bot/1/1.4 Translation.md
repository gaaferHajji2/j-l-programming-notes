**Course Plan**

This course was downloaded for free from the website https://ssl.band/ — Join the closed educational platform!

During the course you will:

- Learn what aiogram and asyncio are  
- Study the Telegram API in detail  
- Learn to build the project architecture  
- Study PostgreSQL and learn to work with SQL  
- Visually understand how to work with the API of banking services  
- Understand how to set up the bot’s interaction with a chat or channel  
- Solve tasks for each section. They are located throughout the course and in the final control work. Each task is a necessary block of knowledge; by studying it you become one step closer to an Aiogram expert.

At the end of the course a glossary of terms is provided that will be used throughout the course. If something is unclear to you, refer to it.

There is also an instruction on handling exceptions. For example, if from the context you understand that the result when pressing a button should be one thing, but you get something different, and in the console you see a bunch of incomprehensible text, then check the chapter “Frequently Asked Questions”. It may already contain information on how to solve the problem. If there is no answer there, write to our manager.
