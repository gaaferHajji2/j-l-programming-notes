### **Asynchronous Programming in Python**

In Python, the `asyncio` library is used for writing asynchronous code. In this section, we will focus specifically on this library, as it is an integral part of the **Aiogram** library, which is used to create Telegram bots.

The main component of asynchronous code is **coroutines** — asynchronous functions that execute code without blocking the main execution thread. Let’s look at how to create a coroutine:

```python
import asyncio

async def main():
    ...

asyncio.run(main())
```

The difference between coroutines and regular functions lies in the use of the keyword `async`, which indicates that the function is asynchronous.

Let’s add some "content" to the `main` function. Suppose it prints all numbers from 1 to 100:

```python
import asyncio

async def main():
    for i in range(1, 100):
        print(i)

asyncio.run(main())
```

In the console, we will see what seems like a normal result of executing a `for` loop — and indeed, it is. At this point, the features of asynchronous programming are not noticeable because there is only one process — the `main` function. The differences will become apparent when we configure interaction between two asynchronous functions.

To call a coroutine from another function, you must use the special keyword `await`, followed by the function name and its arguments — just like with a regular function.

```python
async def func():
    ...

async def main():
    await func()

asyncio.run(main())
```

Inside coroutines, you can write any logic, just as in regular functions. Overall, working with coroutines is completely analogous to working with functions, except you have to use the words `async`/`await`.

#### **The `time` Library**

There is a fairly popular library called `time`. It is built into Python’s standard package modules and does not require additional installation. It is frequently used and has many useful methods. Using this library, you can get the current time.

```python
import time
print(time.time())
```

The result of executing this code will be a 10-digit number, for example: `1712743098`. This might seem like a strange value, but actually, this method returns time in **UNIX format**. This format shows how many seconds have passed since the beginning of the digital era, or the "UNIX epoch," which started on January 1, 1970. To convert this time into a format understandable to ordinary users, we use the same library.

```python
import datetime
import time

now = time.time()
readable_time = time.strftime("%a, %d %b %Y %H:%M:%S", time.localtime(now))
```

We will get the following program output: `Wed, 10 Apr 2024 14:07:03`.

UNIX time is used for storing time in databases because it is easier to store a single number than multiple values characterizing a date. Moreover, it can be conveniently converted into the desired format using built-in methods of the `time` library.

#### **Delay**

The second main application of the library is establishing a delay in the program. For this, the `sleep` method is used.

```python
print("Start of program")
time.sleep(5)
print("End of program")
```

In this example, exactly 5 seconds will pass between the start and end of the program. This method has one drawback: it can only be used in synchronous programs, because this method completely blocks the possible execution of other functions.

The `asyncio` library has its own delay function, which does not prevent the execution of other coroutines and regular functions.

```python
async def func():
    print("Start of program")
    await asyncio.sleep(5)
    print("End of program")

asyncio.run(func())
```

Thus, you can pause the execution of one coroutine for some time, while other coroutines continue to execute.

Next, we will look at how to run multiple coroutines in a single thread.

#### **Creating Tasks**

To fully utilize asynchronicity, you need to create **tasks**, into which we place coroutines that will execute asynchronously. If we want to create a task, we use the method `asyncio.create_task(func())`, where `func` is the coroutine being called.

Let’s consider an example. We will create two coroutines and place them in tasks. If the program executed synchronously, the total time would be 2 + 1 = 3 seconds. To verify the execution time of the asynchronous program, we will define a simple "stopwatch" using the `time` library.

```python
import asyncio
import time

async def f2():
    await asyncio.sleep(2)
    print('f2 end')

async def f1():
    await asyncio.sleep(1)
    print('f1 end')

async def main():
    task1 = asyncio.create_task(f1())
    task2 = asyncio.create_task(f2())
    await task1
    await task2

start = time.time()
asyncio.run(main())
print('Program execution time:', time.time() - start)
```

The result of the program will be the calculation of the time spent using the asynchronous approach — 2 seconds. Thus, we confirmed the fact that the program executes asynchronously.

If we have several tasks starting simultaneously, the processing time for the stream of tasks will be determined by the duration of the longest stream (in this example — 2 seconds).

#### **Alternative**

You can also use another method for asynchronously calling multiple functions:

```python
async def main():
    await asyncio.gather(f1(), f2())
```

Inside the `asyncio.gather` method, we simply list all the coroutines we want to call.

#### **Usage in a Bot**

Let’s apply the skills we’ve acquired. We will create a function that handles user entry into the bot. We will make a welcome message, as well as a message that will be sent 30 seconds after that. It may contain some advertising or content that additionally engages the user.

Suppose we have a bot selling educational content related to neural networks such as ChatGPT, Claude, etc.

In this example, as an idea for such engaging content, we can use gifts — instructions on how to work effectively with artificial intelligence.

Let’s provide the code for the handler of the start message, where a new waiting technology is used.

```python
@router.message(CommandStart())

    await message.answer_photo(img, reply_markup=keyboards.start.menu)
    await asyncio.sleep(30)
    await message.answer(f'''Glad to see you😊.
Three times a week, useful content will arrive. In the form of articles, short lessons, prompts, and collections of neural networks for different professions.
And meanwhile, here is a small gift from me in the form of guides on working''', reply_markup=keyboards.start.present)
```

Place `start.jpg` — an image that will be sent along with the text as the start message — in the `files/media` directory.

In the file `keyboards/start.py`, create two keyboards: the first will open the bot menu, and the second will send the gift.

```python
menu = InlineKeyboardMarkup(
```
