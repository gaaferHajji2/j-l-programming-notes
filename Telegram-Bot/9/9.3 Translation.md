### **Translation: 9.3 Background Process**

**Periodic Function – Periodic Task**

"Periodic" refers to a common practice in asynchronous programming. Let’s consider a situation where we need to send out mailings at regular intervals, while the bot must continue working throughout this time. Naturally, we will use asynchronous programming to solve this task. We will write a function that asynchronously performs some action alongside incoming requests to the bot.

```python
# Periodic function
async def periodic():
    while True:
        print('New step of the function')
        await asyncio.sleep(5)

# Function to start working with the bot
async def init_bot():
    # Initialize handlers
    dp.include_router(handlers.example.router)
    # Start the bot
    await dp.start_polling(bot)

# First coroutine, opening two processes: starting the periodic task and starting the bot
async def main():
    task1 = asyncio.create_task(periodic())
    task2 = asyncio.create_task(init_bot())
    await task1
    await task2

# Entry point
if __name__ == '__main__':
    asyncio.run(main())
```

This kind of template represents a function that performs some action at equal time intervals, i.e., periodically. Inside the `periodic` function, there can be any logic we need: iterating through a database or list of users to perform a mailing; simple logging, outputting the current time to the console.

**Store – "Audience Warm-up"**

Imagine we are creating a commercial bot, inside of which a user personal account will be developed with some free functionality, and each person will possess a certain number of "coins" – an internal currency – from the very start of using the bot. This currency can be spent on some small services within the bot, such as creating images using neural networks or sending anonymous valentines – anything you like.

Let’s make it so that every day the number of coins for each user increases by 10. To do this, we will create a `periodic` function with an infinite loop, inside which we will place a condition comparing the current time with midnight:

```python
async def periodic():
    while True:
        now = time.strftime("%H:%M", time.localtime(time.time()))
        if now != '00:00':
            await asyncio.sleep(50)
            continue
        # Main code will go here
```

If the time is not 00:00, the function will retry the check after 50 seconds; otherwise, it will perform the action we need.

Let’s create a dictionary `base`, which will serve as a prototype for a database (we will create a proper one in the next chapter). Inside the function, we will iterate through our "database" using a `for` loop, increasing the number of coins. We will output the result to the screen and set a timer for 23 hours. This is done to reduce the load on the server, since midnight certainly won’t occur again in the next 23 hours. The final code will look like this:

```python
import time
import asyncio

base = {1046276866: 2, 504678899: 7, 129003420: 1}

async def periodic():
    while True:
        now = time.strftime("%H:%M", time.localtime(time.time()))
        if now != '00:00':
            await asyncio.sleep(50)
            continue
        
        for user_id in base:
            money = base[user_id]
            base[user_id] = money + 10
            
        print(base)
        await asyncio.sleep(23 * 60 * 60)
```

The `periodic` function is located in the `main.py` file or in the `utils` folder in a file with any name you choose; just remember to specify the path to this function when launching it from `main.py`.

Thus, a periodic function was created that credits each user with 10 coins once a day. The application of such a function is limitless, and it is often used in the practice of creating Telegram bots.
