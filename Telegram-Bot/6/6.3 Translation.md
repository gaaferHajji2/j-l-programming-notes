### 📖 English Translation

**Introduction**
Inline keyboards are a type of keyboard that are placed directly under the message they are attached to. Inline keyboards look like this:
*(Image placeholder omitted in text)*
These buttons are often the preferred choice. They not only look more aesthetic, but they also do not take up permanent space on the screen like a standard button panel does. This frees up space for content and makes the interface cleaner and more user-friendly.
Additionally, inline buttons can be configured to display the same text but perform different functions depending on the context.

**Creating a Keyboard Object**
We will write the code in the `keyboards` folder, inside the `example.py` file. To create a basic inline keyboard, you need to import the necessary classes from `aiogram.types`: the keyboard object `InlineKeyboardMarkup` and the button object `InlineKeyboardButton`:

```python
from aiogram.types import InlineKeyboardButton, InlineKeyboardMarkup
```

Next, we will create the keyboard similarly to its reply counterpart:

```python
inline_kb = InlineKeyboardMarkup(
    inline_keyboard=[
        [
            InlineKeyboardButton(text="Информация", callback_data='information'),
            InlineKeyboardButton(text="Оформить подписку", callback_data='subscribe'),
        ],
    ],
)
```

The differences from reply keyboards are as follows:
1. Inline keyboards use different class names – `InlineKeyboardMarkup` and `InlineKeyboardButton`, as opposed to `ReplyKeyboardMarkup` and `KeyboardButton` used for reply keyboards.
2. Instead of the `keyboard` argument used for creating reply keyboards, the `inline_keyboard` argument is passed to the `InlineKeyboardMarkup` constructor.
3. Inline buttons **must** have the `callback_data` argument specified. This special argument is used to identify button presses. Unlike the text in reply keyboards, `callback_data` allows you to create keyboards with identical button labels but different underlying functions.

**Using in the Bot**
Let's create a handler in the `main` file that will send the inline keyboard (created as an example in the previous section) after receiving any message.

```python
import keyboards

@dp.message()
async def start(message):
    # Reply to the message
    await message.answer("Have a nice day!", reply_markup=keyboards.example.inline_kb)
```

Now, whenever we send any text message, the bot will reply with `"Have a nice day!"` along with the attached keyboard.

**Simplified Handling of Inline Button Presses**
To trigger an action when a button is pressed, the `@dp.callback_query` decorator is used. We will use it to handle presses on the button with `callback_data="information"`.

```python
@dp.callback_query(F.data == 'information')
async def info(call):
    print('User pressed the button')
```

This handler will only activate if the pressed button had `callback_data="information"`. To change the activation condition for this function, you need to modify the text inside the decorator's argument on the first line of code.
