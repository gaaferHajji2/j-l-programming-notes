### 🌍 Full English Translation

#### Introduction
The button panel in Telegram bots is called a **keyboard**. In this lesson, we will only cover its basic usage.

If you want to create a keyboard fixed at the bottom of the chat screen, use the `ReplyKeyboardMarkup()` method. This keyboard allows the user to select one of the provided options, and the selected text is automatically sent to the bot as a regular message. This is particularly useful for simplifying input and improving the bot's usability.

`ReplyKeyboardMarkup()` serves as a template for creating messages that contain buttons. For example, your bot can ask a question and offer several answer options. The user can either type a response manually or tap one of the provided buttons. A keyboard created with `ReplyKeyboardMarkup()` is **not tied to a specific message**; it remains visible until replaced or removed.

#### Application of `ReplyKeyboardMarkup()`
`ReplyKeyboardMarkup()` is frequently used to create keyboards with basic and most commonly used buttons. Such keyboards may contain navigation elements to other important sections, such as `"Main Menu"`, `"Payment"`, or `"Settings"`. These buttons can open new keyboards with related functionality, providing a convenient and logical interface for interacting with the bot.

Additionally, `ReplyKeyboardMarkup()` can be used to build **multi-level menus**. For instance, tapping `"Main Menu"` could reveal a keyboard with more specific options like `"My Profile"`, `"Settings"`, or `"Help"`. This allows the bot to offer contextually relevant choices, simplifying navigation and user interaction.

#### Creating a Keyboard
Open the `keyboards` folder and create a file named `example.py`. All code for this section will go in this file.

First, import the necessary modules:
```python
from aiogram.types import ReplyKeyboardMarkup, KeyboardButton
```

To create a keyboard object, use the following structure:
```python
menu = ReplyKeyboardMarkup(keyboard=[[KeyboardButton(text="Information")]])
```

#### Using the Keyboard When Sending Messages
Import the package containing your keyboard:
```python
import keyboards
```

To display the keyboard to the user, create a handler that sends a message along with the buttons. Use the `reply_markup` argument to attach the keyboard to the message. Also, create a handler to process button presses.

```python
import keyboards

@dp.message(F.text == "Information")
async def get_info(message):
    # Reply to the button press
    await message.answer("You can find all the necessary information on our website", 
                         reply_markup=keyboards.example.remove)

@dp.message()
async def start(message):
    # Reply to any other message
    await message.answer("Hi!", reply_markup=keyboards.example.menu)
```

When a user sends any message, the bot replies with `"Hi!"` along with the attached keyboard. If the user taps the `"Information"` button, the bot responds with `"You can find all the necessary information on our website."`

**⚠️ Important Notes:**
- You **cannot** send or update a keyboard separately without sending a message.
- Handlers that process text messages **without specific conditions** (unfiltered text handlers) must always be placed at the **end** of your handler list. This ensures that specific conditions are checked first. If you swap the handlers in the example above, the greeting handler will catch every message first, preventing the button-specific handler from ever triggering.

#### Multi-Button Layouts
Now, let's see how to create a keyboard with multiple buttons. Recall our initial example:
`menu = ReplyKeyboardMarkup(keyboard=[[KeyboardButton(text="Information")]])`

The `keyboard` argument in `ReplyKeyboardMarkup` accepts a **matrix of buttons** (a list of lists). Each inner list represents a single row. For example, the first list contains all buttons for row 1, the second list for row 2, and so on.
