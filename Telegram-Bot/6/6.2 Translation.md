### 📖 English Translation

**Introduction**
In the previous chapter, we covered the foundational knowledge required to create reply keyboards. In this lesson, we will explore everything you might need in this domain. Let's begin by examining a couple of interesting keyboard types that function as standalone objects.

**Hiding the Keyboard**
Sometimes it becomes necessary to hide the keyboard, particularly when it is no longer needed for further interaction with the user. In such cases, you can use a keyboard remover object. This allows you to clear the current keyboard from the screen, freeing up interface space for other elements.

**Force Reply**
Another useful keyboard type is the force reply keyboard. It comes in handy when you need to draw the user's attention to a specific message within a conversation chain. This keyboard type highlights the main message in a series of bot messages. For example, if a bot sends two messages in a row: one asking the user to input a number, and another providing an example of such a number, you can attach a force reply keyboard to the first message. This helps the user clearly understand what action is expected of them.

**Arguments for Creating Reply Keyboards**
Let's look at a basic example of keyboard creation:
```python
main_kb = ReplyKeyboardMarkup(
    keyboard=[
        [
            KeyboardButton(text="Информация")
        ]
    ]
)
```
We will use this base structure to create new keyboards using additional parameters.

**Automatic Keyboard Sizing**
The `resize_keyboard` argument is used to make buttons more compact and visually comfortable. When enabled, the keyboard automatically scales the buttons to fit their content and the device's screen width. To use it, simply add `resize_keyboard=True` after the `keyboard` parameter.

**Custom Input Field Placeholder**
By default, Telegram displays `"Message..."` in the text input field across all chats. To customize this, pass the `input_field_placeholder="your_text"` argument when creating the keyboard, replacing `"your_text"` with your desired prompt.

**One-Time Keyboard**
A one-time keyboard displays its buttons only once. This is controlled by the `one_time_keyboard` argument, which accepts a boolean value (default is `False`). When set to `True`, the keyboard appears on the first message and automatically disappears after the user presses any button. However, the user can still manually reopen it by tapping the keyboard icon next to the text input field.

**Persistent Keyboard**
A persistent keyboard gives the user continuous access throughout the chat session. The `is_persistent` argument determines whether the keyboard can be manually toggled (default is `False`). When set to `True`, the manual toggle button disappears, and the keyboard automatically collapses when the user starts typing in the input field. This helps maintain a cleaner interface during active text input.
