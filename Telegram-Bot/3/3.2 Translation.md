## Obtaining an API token for a future bot

To start working with a Telegram bot, we need to obtain an API token for the future bot.

To do this, go to the official Telegram bot — @BotFather and click the "Start" button at the bottom of the screen. If the button does not appear, enter the /start command in the chat.

## Creating a bot

Click on the blue "Menu" button located in the lower left corner of the dialog and in the window that appears, select the command "Create a new bot - /newbot" to create a new bot.

A new message appears from BotFather asking us to enter the future name of the bot, which will be visible to all users. Enter the future name. The image shows an example of how this should look.

**Page 2**

## Creating a @username

Next, we will be asked to enter a username (user name / bot name), which will later serve as a link to your bot. The username must end with _bot, but there are also spelling variations without an underscore, such as: usernamebot, usernameBot, usernameBOT.

## Obtaining the API

We have registered our bot (you can go to it via the link provided in the message) and received an HTTP API token for further work, which you can copy by simply clicking on it.

**Page 3**

<center>! IMPORTANT !</center>

Do not share your bot's token with anyone and store it in a safe place. If the token falls into the hands of people with bad intentions, this can lead to very unpleasant consequences.

But I hasten to reassure you. If you accidentally leaked this token on the internet or attackers stole it from you, you don't need to create a new bot. You can always block the old token and issue a new one. Your actions will be roughly similar to if you lost your bank card.

**Page 4**

I would like to add that you can create up to 20 API tokens without a Telegram Premium subscription and 40 API tokens with a subscription.
