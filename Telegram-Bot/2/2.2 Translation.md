**What is aiogram**

Aiogram is a modern, rapidly gaining popularity library for the Python programming language that makes it possible to create Telegram bots. It provides a convenient and powerful interface for interacting with the Telegram API. This library is written on the basis of Asyncio and Aiohttp (asynchronous HTTP client/server for the asyncio module), thanks to which asynchronous code execution is implemented. This allows the bot to continue working without stopping while waiting for a user’s response.

Version 3.0 is actively developing at the moment. Literally every month new updates are released that, with only a slight delay, correspond to everything Telegram adds for regular users. By using this version of the library, you will be able to respond to the modern capabilities of this messenger and use the very latest features.
