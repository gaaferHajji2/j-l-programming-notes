# Translation: Arguments to Commands (Aiogram)

## Main Content Translation

### Passing Arguments to Commands

Suppose we want to pass some data along with a command, for example, a message to administrators. **Aiogram** provides this capability. You need to add the `command` argument to the message handler function. To retrieve the data that the user types after the command, use the `command.args` method.

```python
@router.message(Command('help'))
async def help(message, command):
    await message.answer(f'''Your issue: {command.args}
The message will be forwarded to administrators shortly.''')
```

**Example of how this looks in the bot:**
> User types: `/help I can't log in`  
> Bot replies: *Your issue: I can't log in. The message will be forwarded to administrators shortly.*

---

### Automatic Argument Input (Deep Linking)

**Aiogram** supports embedding arguments directly into the bot start link:

```
https://t.me/{username}?start={some_text}
```

- `{username}` — the Telegram bot's nickname  
- `{some_text}` — the argument being passed

**Example:**  
A user clicks the link:  
```
https://t.me/my_bot?start=shop
```

And the bot `@my_bot` has the following handler implemented:

```python
@router.message(Command('start'))
async def start(message, command):
    if command.args == 'shop':
        await message.answer('Welcome to the store menu')
    elif command.args == 'feedback':
        await message.answer('Here you can leave your feedback')
    else:
        await message.answer('This command is not supported. For more information about our commands, press /help')
```

When the user clicks the **[Start]** button that appears, they will receive the message: *"Welcome to the store menu"*.

Similarly, you can implement any logic for links pointing to your bot. This allows you to place links to specific bot sections on different parts of your website, helping users navigate without confusion.

## Quick Reference: Code Syntax

```python
# Getting arguments after a command
@router.message(Command('help'))
async def help_handler(message: Message, command: CommandObject):
    user_input = command.args  # ← Everything after "/help "
    await message.answer(f"You wrote: {user_input}")

# Deep link structure
# https://t.me/YourBot?start=shop
#                          ↑
#              command.args will equal "shop"
```
