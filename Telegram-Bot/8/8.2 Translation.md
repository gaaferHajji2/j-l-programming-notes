# Translation: 8.2 Special Features (Telegram Bot Development)

## Full Translation

**Command Menu**  
In BotFather, there is an option to create a command menu that will be displayed in the bottom-left corner. To add commands to your bot, go to BotFather and select your bot. Click on the button **Edit bot** → **Edit Commands**.  
Then send the command name and its short description following the specified format. As a result, you will receive a menu with commands that can be clicked and will automatically be entered into the chat.

**Changing Command Prefix**  
The symbol by which commands are recognized can be changed. By default, this prefix is the "/" symbol. To change it for a specific command, specify the new prefix in the arguments of its filter.

```python
@router.message(Command('help', prefix='!'))
async def help(message):
    await message.answer('For assistance, contact the administrator @dmiii7')
```

This is how it looks in the bot.  
Similarly, you can use any symbol, for example: "@", "|", etc.
