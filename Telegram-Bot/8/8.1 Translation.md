# Translation: Command Handling (8.1 Обработка команд)

## Introduction
Commands are messages that begin with a special character (originally "/"). They must be written in Latin script. Here are examples of commands: `/start`, `/help`, `/menu`. Commands are used for quick navigation to specific sections within a bot and serve as a simplified alternative to buttons. You can create a message containing commands and their descriptions, allowing users to click on them. An example of such a message can be seen in **BotFather**.

## Start Command in Aiogram
In the `handlers` folder, create a file named `start.py`. Inside it, create a router object similar to the previous chapter, and declare the router in the `main.py` file. Import the filter object that handles the start command `/start`, which is triggered when the user presses the **[Start]** button.

```python
from aiogram.filters import CommandStart

@router.message(CommandStart())
async def start(message):
    await message.answer('We are glad to see you in our bot')
```

Thus, when a user enters the bot, they will receive a welcome message. The same message will be sent if the user manually types `/start` in the chat with the bot.

## Custom Commands
Let's create a `/help` command. To do this, import the customizable command filter object and specify the command name as its argument.

```python
from aiogram.filters import Command

@router.message(Command('help'))
async def help(message):
    await message.answer('For assistance, contact the administrator @dmiii7')
```
