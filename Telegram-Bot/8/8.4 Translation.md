### **Translation: 8.4 Referral System**

**Introduction**
Let’s create a referral system in the bot. Its essence is as follows: a user sends their individual link to the bot to a friend. When the friend follows this link, the first user’s counter of invited people increases. Typically, this counter also affects additional user benefits, such as granting free subscriptions to users with more than 10 invites, participation in giveaways, income from referrals' purchases, and so on.

We will implement a slightly simplified version: the counter in the personal account will increase when friends are invited.

**Getting Started**
In the `handlers` folder, create a file named `referrals.py`. In it, import the basic modules and create a router object, which must also be declared in the `main.py` file.

Create a dictionary (a prototype database) where the keys represent each user, and the values contain a list of that user’s referrals.

Create a handler that consists of:
1. A welcome message.
2. Adding a new user/referral to the database.
3. Retrieving the ID of the user who created the referral link.
4. Adding the referral to the inviter’s list, provided the referral hasn’t used the bot before.

```python
users = {}

@router.message(CommandStart())
async def start(message, command):
    # Welcome message
    await message.answer(f'Welcome, {message.from_user.first_name}')
    
    user_id = str(message.from_user.id)
    ref_id = command.args
    
    if user_id not in users:
        # Add new user to the database
        users[user_id] = []
        
    if ref_id is None:
        return
        
    # If an argument is provided with the command
    try:
        users[ref_id].append(user_id)
    except KeyError:
        pass
```

Thus, we have created a handler for the start message that establishes a connection between referrals and those who invited them.

import config

@router.message(Command('ref'))
async def ref(message):
    user_id = str(message.from_user.id)
    await message.answer(f'''⚙️ You have opened the employee personal account

**Conclusion**
Thus, a model of a real referral system was created, featuring the ability to invite new users to our bot and view statistics in the personal account.

In this implementation, we did not use databases. This is a disadvantage of this method, as the dictionary will be reset after every bot restart, unlike a database. In upcoming chapters, we will become familiar with databases and examine their main advantages. This lesson allowed us to acquaint ourselves with the concept of a referral system and inviting friends to our bot.
